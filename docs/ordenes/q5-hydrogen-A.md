2. **Autorización del cliente (portal a 390×844):** Envía el presupuesto desde `AuthorizationPanel` aceptando el diálogo `confirm()` del navegador (`Enviar presupuesto` / `Send estimate`). ## Selectores y comportamientos por verificar en ejecución

No se ejecutaron comandos ni la suite Playwright desde este entorno (restricción de la tarea). Puntos principales a confirmar cuando el verificador corra `npm run lint`, `npx tsc -b` y `npm run test:e2e:local -- e2e/un-dia-en-el-taller.spec.ts`:

- **Paso 1 (`VehicleFields.tsx` / `Combobox`):** Al llenar `Marca|Brand` (`Toyota`) y `Modelo|Model` (`Camry`), se hace clic en `getByRole('option', { name: 'Toyota', exact: true })` y `getByRole('option', { name: 'Camry', exact: true })` para cerrar el menú antes de pasar a `Año|Year`. Por verificar que las sugerencias locales se muestran de inmediato sin latencia de la API externa vPIC.
- **Paso 1 (`TaskEditor` y `PartEditor` en `WorkStep`):** Uso de `modal.getByRole('group', { name: /Nuevo trabajo|New job/ })` y `modal.getByRole('group', { name: /Nuevo repuesto|New part/ })` junto con `getByLabel(/Técnico|Technician/).selectOption(mechanicId)` en lugar de IDs internos.
- **Paso 3 (`UploadTray`):** Se espera el texto visible `/1 de 1 archivos subidos|1 of 1 files uploaded/` sin usar `.upload-tray`, seguido de `expect.poll` en `orden_avances` y `orden_media`. Por verificar que el texto aparece antes de cualquier limpieza automática de la bandeja.
- **Paso 4 (`ReadyNotifyModal`):** Según `useOrderTransitions.ts`, al marcar lista una orden cuyo cliente no tiene correo, se abre `ReadyNotifyModal` automáticamente (`Avísale al cliente...` / `Let the customer know...`). Por verificar que el clic en `Cerrar|Close` lo cierra antes de pulsar `Entregar y cobrar`.
- **Paso 4 (`OrderHeader` tras entregar):** Se comprueba `page.getByRole('heading', { name: /Entregado|Delivered/ })` en el encabezado `h1` de la orden.
- **Paso 5(a) (`Finance.tsx`):** Como `/finance` no tiene caja de búsqueda y renderiza dos tablas (`OrderMarginCard` arriba y la tabla de movimientos abajo), se filtró la fila con `.filter({ hasText: numero }).filter({ hasText: /Zelle/i })`. Por verificar si en una corrida con muchos movimientos la fila es visible de inmediato sin desplazamiento adicional.
- **Paso 5(b) (`src/portal/strings.ts`):** En inglés, `portalStrings.en.status.entregado` es `'Picked up'` (no `'Delivered'`), por lo que la aserción comprueba `'Picked up'`.
