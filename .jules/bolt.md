## 2024-09-12 - Recomputing derived aggregations over list map calls
**Learning:** In React components dealing with aggregates (e.g., maximum revenue to scale chart bars relative to their height), placing `.map` or `.reduce` computations to find max scalar values *inside* the outer rendering array's `.map()` creates a silent O(N²) loop that repeats every render cycle, computing identically for every item in the list instead of caching it across bars.
**Action:** Always compute derived array metrics (like a `Math.max` for scaling bounds) once at the top level of the component scope using `useMemo` so it computes in O(N) only when the array data changes, and pass that cached scalar into the rendering map.
